# Documentación de I-CASE Tool

Sitio de documentación (Docusaurus) que se publica en `/docs` de la misma aplicación.

- `npm run docs` (desde la raíz del repo): servidor local en http://localhost:3001/docs/
- `npm run docs:build`: genera el sitio en `public/docs`

Ver [Por qué Docusaurus](docs/desarrolladores/herramienta-de-documentacion.md).
